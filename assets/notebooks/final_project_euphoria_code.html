Module 3 — Pipeline Helper and Tuning Configuration

The module starts with def make_pipe(estimator, scale=True):, which defines a reusable pipeline builder so that every classifier in the study follows the exact same preprocessing flow, eliminating inconsistency between models. The accompanying docstring """Imputation + (optional) scaling + estimator. Tree models don't need scaling.""" documents the function's behavior and clarifies why the scaling step is optional, since tree-based models are scale-invariant and gain nothing from standardization. Inside the function, steps = [('impute', SimpleImputer(strategy='median'))] initializes the pipeline with median imputation as the first step, ensuring that missing values in features such as pH, Sulfate, and Trihalomethanes are filled using a robust statistic that is fit only on training folds. The conditional if scale: then checks whether the current model is scale-sensitive, and when true, steps.append(('scale', StandardScaler())) adds standardization for distance-based and gradient-based models like KNN, Logistic Regression, and SVM, while tree-based models bypass this step entirely. Next, steps.append(('clf', estimator)) appends the chosen classifier as the final stage of the pipeline, and return Pipeline(steps) returns the completed scikit-learn Pipeline object that bundles preprocessing and modeling into a single, leak-proof unit. After the helper function, SCORING = 'f1' sets F1-score as the optimization metric for hyperparameter tuning so that both precision and recall are balanced — a more honest objective than accuracy on this imbalanced dataset — and tuned = {} initializes an empty dictionary that will later store the best tuned estimator from each model's GridSearchCV run. Overall, this module standardizes the preprocessing and evaluation rules across the entire workflow so that all five classifiers are tuned fairly, consistently, and without any risk of data leakage from the test set into model selection.

[7]:
def make_pipe(estimator, scale=True):
    """Imputation + (optional) scaling + estimator. Tree models don't need scaling."""
    steps = [('impute', SimpleImputer(strategy='median'))]
    if scale:
        steps.append(('scale', StandardScaler()))
    steps.append(('clf', estimator))
    return Pipeline(steps)

SCORING = 'f1'   # We optimize for F1-Score instead of Accuracy due to the imbalance
tuned = {}       # will hold the best estimator for each model

# Sigmoid Curve for  Models (Logistic Regression, SVM)
def plot_sigmoid_curves(tuned_models, X_test, y_test):
    applicable = ['Logistic Regression', 'SVM']

    for name in applicable:
        if name not in tuned_models: continue

        model = tuned_models[name]
        # For LR, we can use log-odds. For SVM, we use the decision function.
        if name == 'Logistic Regression':
            clf = model.named_steps['clf']
            X_transformed = X_test.copy()
            for step_name, step in model.steps:
                if step_name == 'clf': break
                X_transformed = step.transform(X_transformed)
            scores = np.dot(X_transformed, clf.coef_.T) + clf.intercept_
            scores = scores.flatten()
            xlabel = 'Log-Odds (Linear Combination)'
        else: # SVM
            scores = model.decision_function(X_test)
            xlabel = 'Distance to Hyperplane (Decision Function)'

        probs = model.predict_proba(X_test)[:, 1]

        plt.figure(figsize=(6, 4))
        sorted_idx = np.argsort(scores)
        plt.plot(scores[sorted_idx], probs[sorted_idx], color='blue', linewidth=2, label='Sigmoid Fit')

        jitter = np.random.uniform(-0.03, 0.03, size=len(y_test))
        plt.scatter(scores, y_test + jitter, color='red', alpha=0.15, s=10, label='Actuals')

        plt.axhline(0.5, color='black', linestyle='--', alpha=0.3)
        plt.axvline(0, color='black', linestyle='--', alpha=0.3)
        plt.title(f'Sigmoid Probability Curve: {name}')
        plt.xlabel(xlabel)
        plt.ylabel('Predicted Probability')
        plt.legend()
        plt.grid(True, alpha=0.2)
        plt.savefig(f'sigmoid_{name.lower().replace(" ", "_")}.png', dpi=300)
        plt.show()
